## Exercises Overview

| # | Exercise | Topics Covered |
|---|----------|---------------|
| 1 | Kubernetes Getting Started | Pods, Minikube, nginx |
| 2 | Minikube + Kubectl + Flask | Deployments, Services, Flask on K8s |
| 3 | Scaling Flask with ReplicaSets | ReplicaSets, Scaling, Load Distribution |
| 4 | Docker Networking | Bridge Networks, Multi-container Apps |
| 5 | Docker Security (AppArmor) | AppArmor Profiles, Container Security |
| 6 | Grafana Real-Time Monitoring | Prometheus, Grafana, Metrics |
| 7 | Jenkins CI Automation | CI Concepts, Jenkins Setup |
| 8 | Jenkins Hello World Job | Jenkins Jobs, Shell Scripts |
| 9 | Jenkins Multi-Stage Pipeline | Jenkinsfile, Build/Test/Deploy |
| 10 | Multi-Node Multi-App Deployment | Multi-node K8s, Multiple Services |
